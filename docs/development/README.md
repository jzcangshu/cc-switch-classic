# 模块开发手册

按本次改动涉及的模块阅读。公共约束见 [项目契约](../maintenance/project-contract.md)，所有新增应用还须完成 [接入核对表](../maintenance/upstream-sync.md#5-新能力与新应用接入核对表)。模块规范不能覆盖经典版的视觉与产品裁决。

| 改动范围                              | 阅读资料                                                       | 职责                                                                     |
| ------------------------------------- | -------------------------------------------------------------- | ------------------------------------------------------------------------ |
| Pi（编程工具）原生文件、认证、资源    | [原生契约](pi-native-contract-zh.md)                           | 配置归属、原子写入、并发保护与会话路径                                   |
| Pi 供应商导入、启用、移除、刷新       | [显式供应商同步](pi-live-provider-sync-requirements-zh.md)     | 精确标识、成员关系、原生修改与未知字段                                   |
| Pi 预设、模型能力与思考档位           | [模型能力与思考档位](pi-thinking-level-map-requirements-zh.md) | 补全来源、协议兼容、稀疏映射与往返验收                                   |
| Pi 表单、提示词、技能、会话界面       | [前端交互与验收](pi-frontend-uiux-guidelines-zh.md)            | 可见字段、操作语义、错误处理及真实联调                                   |
| 供应商分组与拖动                      | [分组与拖动契约](provider-grouping.md)                         | 数据边界、悬停判定、取消、持久化及手感验收；审查含此能力的候选版本时读取 |
| 会话发现、阅读、恢复与删除            | [会话管理](session-manager.md)                                 | 原生适配、结构化内容、目录安全与跨平台验证                               |
| Antigravity CLI（编程命令行工具）     | [接入规范](agy-integration-zh.md)                              | 启动投影、账号、原生资源、深链接与用量                                   |
| Kimi Code（编程工具）配置、账号与会话 | [接入说明](kimi-code-integration.md)                           | 对应原生集成及验证                                                       |

每次从固定候选提交核对实际实现与测试。文档中的规范表示修改必须满足的契约，功能是否已进入发布版本由提交和发布记录确认。
