# Antigravity CLI（编程命令行工具）接入规范

agy（应用标识）独立于 Gemini CLI（编程工具），复用供应商、账号、协议服务器、技能、会话和用量页面。修改时先读 [项目契约](../maintenance/project-contract.md)；会话通用要求见 [会话管理](session-manager.md)。本手册覆盖原生配置与账号服务的不同职责，验收版本以当前任务固定的真实客户端为准。

## 供应商卡片与原生启动

供应商卡片用于“打开终端”，每张卡只影响它启动的会话。模型和其他配置不写入用户的真实全局 settings.json（原生设置文件）。直接运行原生命令仍按原生登录与模型选择工作。

- 官方卡通过 agy --model（指定模型启动参数）传入显示名；未指定时直接运行原生命令。官方身份根据明确分类或预设标识判断，不能因为名称包含厂商名就删除密钥。
- 第三方密钥卡使用 agy --gemini_dir（私有配置根目录参数）启动；目录由供应商标识安全派生，不能让标识造成路径越界。私有设置只存协议选择与模型，密钥和地址通过子进程环境传入。
- 私有目录中的 config（公共配置目录链接）连接原生公共配置，保留协议服务器、技能和提示词共享。Windows（视窗系统）链接权限不足时按实现支持的目录联接路径处理，不复制成另一套独立资源。
- 启动不修改用户的终端启动文件或常驻搜索路径，不安装包装脚本。兼容清理只允许处理项目明确标记的内容，未标记的同名文件和用户其他内容必须保留。
- 删除卡片不删除私有目录里的会话。已经运行的原生进程不热切换；私有目录会话恢复使用同一目录，凭据通过所属卡片的启动路径补充，不能写进恢复命令。

CC Switch Classic（经典版）内部保存 env（环境字段）和 config.model.name（模型名称）结构，原生设置只写经过验证的投影。模型名称优先读取 config.model.name，兼容 GEMINI_MODEL（兼容模型字段）；编辑需按同样优先级写回，不能让隐藏旧值覆盖新输入。

## 凭据、模型与官方账号

密钥和地址都为空时允许原生登录；只填模型不要求密钥。填写密钥可以使用默认端点，自定义地址必须配非空密钥。第三方服务须支持对应 Gemini（模型接口）协议，不能仅因共用表单就宣称其他协议可用。

模型列表来自本机原生命令的已验证输出；显示名、命令别名与服务接口模型标识必须分开。不要以全局字符串替换推测模型名称，也不能拿另一供应商的同名模型能力直接填入。原生客户端版本变化时重新核对模型选择与实际请求。

官方账号由专门账号服务管理，和供应商启动投影区分：

1. 每个账号保存完整登录结构及未知字段，以身份令牌中的稳定 subject（主体标识）区分，不以邮箱显示名判断。
2. 用户明确切换时，先收回系统钥匙串中的当前登录，保留客户端自行续期后的内容；无法识别的原始登录结构保存在受限位置，不能覆盖丢失。
3. 切换写入目标账号的登录，客户端下次启动使用该账号。额度耗尽或请求失败不得自动换号。
4. 在本项目删除账号只删除自己的副本，不替原生客户端退出登录；账号副本不进入云同步。
5. 额度查询所需续期更新本项目副本，不擅自切换系统钥匙串账号。错误、取消、并发切换和登录回调状态都须单独验证。

密钥不进入命令行参数、日志或持久启动脚本。平台启动机制需要临时传递文件时，限定访问权限与寿命，测试其失败清理；不能宣称“没有出现在参数里”就已覆盖所有泄露路径。

## 协议服务器与技能

MCP 支持 stdio 和 Streamable HTTP，兼容导入旧 `serverUrl`，拒绝 agy 不支持的 SSE。禁用写 `disabled: true`，保留本地选项；删除仍启用于 agy 的服务器会移除对应原生条目。数据库的关闭标记不记录托管历史，因此删除未启用于 agy 的服务器时保留原生配置，即使同名禁用条目的传输字段完全相同；如需删除保留的禁用条目，应在 agy 中操作。切换传输方式时清理旧传输字段，保留非传输选项和未托管服务器。数据库提交失败会恢复原文件；重新同步不会因为数据库中的默认关闭标记而删掉未托管条目。

Skills 复用既有 SSOT、下载、链接/复制和备份机制，新增独立持久开关。对同名原生目录先核对内容和归属；外部修改不静默覆盖。更新使用暂存副本，数据库失败时恢复旧文件；显式切换也支持回滚。迁移存储时重定向托管链接，卸载前验证选中的原生副本，保留未启用的外部同名目录。

## 会话和用量

扫描原生命令行、桌面编辑器与供应商私有根目录，按会话标识去重并保留恢复所需根目录。优先只读原生摘要数据库；没有索引时按支持格式解析日志。只有二进制记录的会话可以显示摘要和恢复命令，不能伪造正文。

日志按 step_index（步骤索引）排序，同一步骤重写取有效最新值，容忍未写完的尾部；路径与链接不能指向会话根外。删除由原生应用维护二进制正文和摘要索引，前后端都应明确引导到原应用，不只删除可读日志。

用量仅导入完成的模型响应，输入、缓存、回答与思考按原生日志语义分别处理。合成夹具中的输入总量 100、缓存 20、回答 5、思考 7 应得到普通输入 80、缓存读取 20、输出 12，不能重复扣缓存或重复加思考。

按会话与步骤标识去重，账本和明细同事务提交；保留策略清理明细后不能重复导入。已完成步骤被改写时仅更新仍保留的明细。历史模型从日志的模型切换事件及可靠记录还原，缺失时保持 unknown（未知），不按当前供应商反推。价格使用实际模型定价，未知价格的零费用不代表免费；日志估算费用、账号订阅额度和真实账单分别展示。

## 深链接导入

统一入口是 `ccswitch://v1/import`，agy 使用独立的 `app=agy` / `apps=agy`：

- **供应商**：`resource=provider&app=agy`，支持 `name`、`apiKey`、`endpoint`、`model`、`config` 与 `apiFormat=gemini_native`。不支持 OpenAI/Anthropic 协议。确认框关闭「导入后立即切换」时只保存数据库，不创建原生配置；开启时仍按当前供应商服务的生命周期处理，不能写入真实原生登录配置。带 Key 的供应商导入后经卡片「打开终端」使用。
- **内联配置**：`config` 是 Base64 编码 JSON，可用上文 CCS 的 `{env, config:{model:{name}}}` 结构，或扁平 `GEMINI_API_KEY`、`GOOGLE_GEMINI_BASE_URL`（兼容 `GEMINI_BASE_URL`）、`GEMINI_MODEL`。模型优先级为 URL 的 `model` > `config.model.name` > `GEMINI_MODEL`。只提取密钥、地址、模型，其他环境变量与原生选项不导入；预览中的密钥打码。远程 `configUrl` 仍不支持。
- **MCP**：`resource=mcp&apps=agy`；`apps=agy,codex` 可同时指定多个应用。`config` 为 Base64 编码的 `{"mcpServers":{...}}`。同 ID 已存在时保留数据库中的服务器定义，仅合并应用开关，再走统一 MCP 同步；agy 不支持的 SSE 会报告导入失败。
- **Prompt**：`resource=prompt&app=agy`，`content` 为 Base64 Markdown，确认后保存到 agy 提示词列表；启用时使用既有 Prompt 路径解析和写入逻辑。
- **Skills**：`resource=skill&repo=owner/name&branch=main` 只添加所有应用共享的技能仓库，不下载或安装技能，也不会因附带 `app=agy` 自动启用。随后在 Skills 页面选择技能并为 agy 启用。

供应商示例（所有凭据都是占位值；链接参数需 URL 编码）：

```text
ccswitch://v1/import?resource=provider&app=agy&name=Antigravity&endpoint=https%3A%2F%2Fgenerativelanguage.googleapis.com&apiKey=YOUR_KEY&model=YOUR_MODEL&apiFormat=gemini_native&enabled=false
```

深链接供应商沿用现有 API Key 导入规则，需要密钥和端点；不通过链接导入或接管 OAuth 登录。会话预览、Token 统计和会话恢复不是导入资源，没有新增对应 `resource` 类型。

## 验证

- 原生配置：官方卡按会话指定模型、第三方卡隔离目录、真实全局设置不被改写、公共资源链接正确、损坏配置不会被当空文件覆盖。
- 模型与表单：模型来源、显示名/标识区别、默认端点、只有模型无密钥、原始字段优先级与旧配置往返。
- 账号：稳定身份、切换前收回当前登录、未知字段保留、删除不登出、续期与额度、取消及并发错误。
- 协议与技能：独立应用开关、支持的传输、未托管资源保护、数据库失败回滚、共享资源迁移。
- 会话与用量：多根目录、私有恢复、越界链接、改写与残缺日志、去重和费用口径。真实夹具仅保存合成或脱敏内容。
- 终端：密钥传递不出现在参数和日志，空地址不会继承错误环境变量，路径含空格或非英文字符时正确启动，各平台资源清理有效。

原生冒烟测试使用隔离用户目录和工作目录，配置由受限临时文件提供，不读真实用户数据库。默认忽略的联网测试只有在任务明确授权后运行。命令退出成功还须检查实际回答、权限拒绝和请求内容；本地模拟服务验证协议，真实客户端验证加载与行为，两种证据分别记录。
