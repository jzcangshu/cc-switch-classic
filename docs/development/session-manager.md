# 会话管理开发与验收规范

本模块在本地发现会话、展示结构化内容，并提供恢复、导出和删除操作。修改会话适配器、阅读器或终端启动时读取；新增应用同时完成 [接入核对表](../maintenance/upstream-sync.md#5-新能力与新应用接入核对表)。界面形态见 [裁决手册](../maintenance/upstream-triage.md)。

## 原生适配与职责

支持的应用、平台和文件格式以候选提交中的适配器与注册入口为准。按以下边界扩展，复用统一列表和阅读器：

| 边界             | 职责                                             | 不变量                                             |
| ---------------- | ------------------------------------------------ | -------------------------------------------------- |
| 路径解析         | 配置覆盖、应用默认根目录、平台与项目上下文       | 不猜测活动项目，不越过测试目录读取真实数据         |
| 应用适配器       | 发现、会话标识、元信息、内容解析、恢复与删除规则 | 消费真实原生格式；单个源失败不影响其他应用         |
| 元信息与缓存     | 列表、目录、摘要、时间、来源标识及增量刷新       | 文件变化后失效；同一会话不能因索引和正文形成重复项 |
| 内容模型与阅读器 | 消息、思考、工具、图片、事件、结构化块及内容引用 | 保留角色与顺序；大内容按需读取，不退化为拼接全文   |
| 终端启动         | 平台适配、可用终端、工作目录、命令参数           | 参数正确引用；不把原始会话文本作为可执行脚本       |

新增适配器不能只加扫描分支：核对命令注册、前端类型、应用过滤、空态、内容加载、恢复可用性、导出及删除路径。不同应用的数据归属独立；Pi（编程工具）的额外限制见 [原生契约](pi-native-contract-zh.md)。

## 发现、列表与搜索

- 使用原生会话标识与权威来源位置，不用标题或文件名相似性合并会话。目录、摘要和时间未知时保持缺失状态，不制造看似准确的值。
- 区分目录不存在、没有会话、权限不足、格式损坏和读取失败。可识别的元信息保留在列表，详情读取失败给出具体原因。
- 列表先读取必要元信息，打开详情再读正文。缓存或增量索引必须能识别外部修改、文件删除、路径切换和应用设置变化。
- 搜索、应用过滤、按项目组织与排序共用同一可见集合；刷新、批量操作、计数和空态基于真实结果。搜索自动展开项目时明确收起限制。
- 搜索失败和旧请求晚到不能覆盖较新的查询状态。长列表有边界明确的加载与取消策略。

## 结构化详情与性能

保留 user（用户）、assistant（助手）、tool（工具）等角色、消息顺序和工具调用关联。未知原生条目可降级显示或忽略，但不能丢失已支持的结构化内容，也不能因一条未知记录终止整个文件读取。

按需读取正文、分块内容和附件，定位请求绑定会话和来源版本；切换会话后的迟到结果不得写入新会话。图片、文件引用和大段输出遵守读取范围与资源限制。加载失败与空内容分开表示，详情搜索和定位使用真实内容边界。

在代表性的长会话、大附件和大量会话目录下记录扫描、首屏与滚动表现。虚拟列表和尺寸测量要在真实渲染中验证；测试替身不能证明阅读器几何正确。

## 恢复与终端

1. 由应用适配器生成对应会话的恢复命令和可靠工作目录；界面提供可读预览与复制路径。当前应用不支持恢复时解释原因。
2. 已知目录不存在时给出可恢复错误；缺少目录时，只有原生命令允许才按无目录方式恢复，不能猜测用户项目。
3. 参数、目录、引号、空格和命令解释器分别处理；Windows（视窗系统）、macOS（苹果桌面系统）、Linux（类 Unix 系统）按各自终端实现验证。
4. 终端不可用或启动权限不足时，保留复制命令路径和明确错误，不报告已恢复。避免为一次恢复修改用户长期终端配置。
5. 测试使用隔离目录和无副作用命令，不启动真实会话，不向用户正在运行的终端注入文本。

## 删除、导出与隐私

- 读取默认在本地进行；会话正文、真实目录和凭据不得进入公开日志、截图或测试夹具。
- 删除前同时校验应用、会话标识、源路径及所属根目录。处理符号链接、路径穿越、源文件变动和数据库型存储，不能直接按前端传入路径删除。
- 删除同一会话的正文、索引和关联记录遵循该应用的原生语义；仅清缓存不能伪装成删除成功。完成后让列表与内容缓存失效。
- 批量删除逐项返回成功、失败和原因，保留失败项并支持重试；确认范围明确区分全部与筛选结果。
- 导出是用户发起的动作；格式和附件处理有明确边界，安全处理链接与代码块，失败时不能把不完整文件报告为成功。

## 验收矩阵

| 场景       | 验证内容                                                             |
| ---------- | -------------------------------------------------------------------- |
| 原生夹具   | 真实文件头、索引布局、消息类型、标识与序列化往返；数据全部合成或脱敏 |
| 发现       | 默认目录、设置覆盖、目录缺失、多个根目录、外部变化、单源损坏         |
| 列表与搜索 | 混合应用、重复标识、空状态、长目录、过滤、搜索展开、刷新与迟到请求   |
| 内容       | 消息/思考/工具/图片/事件、未知条目、超长输出、分块加载、切换时取消   |
| 恢复       | 命令预览与复制、目录带空格/引号、目录缺失、终端不可用、各平台路径    |
| 删除       | 单项、批量部分失败、越界源、标识不符、并发变更、索引和缓存一致性     |
| 界面       | 左栏刷新/批量/收起、常驻删除、窄窗口、键盘、四语言与暗色主题         |

每次记录实际执行的应用、平台、提交和结果；尚未执行的终端与原生格式验证保留为缺口。
