# 文档治理与公开边界

新增、拆分或归档长期维护资料时阅读。规则应能从 [统一入口](../../AGENTS.md) 按任务阶段找到，不依赖私人聊天、某个助手的本地记忆或全局技能。

## 分层与唯一归属

| 层级           | 位置                                     | 维护原则                                                   |
| -------------- | ---------------------------------------- | ---------------------------------------------------------- |
| 任务入口       | 根目录助手入口、贡献规范、维护入口       | 短导航，只描述阅读顺序和公共底线                           |
| 公开规则       | 本目录的契约、开发、同步、审查、发布文档 | 一条规则只在所属文档完整定义，其余引用                     |
| 模块说明       | 模块就近说明与开发文档目录               | 按任务触发阅读，在 [文档目录](../README.md) 登记           |
| 决策依据       | docs/decisions（决策目录）               | 记录非平凡的理由、备选、代价和验证；不代替现行规则         |
| 用户与历史资料 | 手册、功能指南、发布说明、变更日志       | 保留被引用的使用说明和历史来源，不当作自动执行指令         |
| 私人运维       | 维护者指定的仓库外目录                   | 个人环境、服务器、账号、代理、签名材料位置；不进入版本管理 |
| 一次性材料     | 仓库外档案与审查输出目录                 | 原始交接、聊天、截图、构建和审查日志；只提炼长期知识入库   |

## 助手入口合并

AGENTS.md（统一入口）是唯一完整入口。AGENT.md（单数兼容入口）、CLAUDE.md（助手兼容入口）、GEMINI.md（助手兼容入口）、CODEBUDDY.md（助手兼容入口）及代码托管平台的助手入口只保留短跳转；不再维护并行规则副本。

工具未自动读取入口时，贡献者把统一入口作为首次任务上下文。目录级助手指令若确有局部必要，必须从这里和上级入口能发现，并且只描述局部差异；不能创建隐蔽的全局规则。

私人规则可以补充本地执行条件，不能覆盖公共产品契约，也不能成为其他贡献者无法满足的先决条件。

## 决策记录

沿生命周期和类别组织，按需创建目录：proposed（提案）、implemented（已实施）、rejected（已否决）、archived（冻结归档）；类别为 feature（能力）、bug-fix（修复）、simplification（简化）、architecture（架构）、process（流程）、testing（测试）。文件名采用首次提出日期加主题。

每篇明确标题、状态、问题、决定或提案、真实考虑过的替代方案、收益和代价及验证。优先更新已有决定；决定翻转时另写一篇并引用旧文，不能悄悄把旧结论改成反面。无行为变化的机械改动不写决策。

本项目采用公开的决策目录，使贡献者不依赖被忽略的助手记忆目录；结构检查由文档门禁执行。一次性的私人工作日志不放到这里。

## 资料归并与归档

1. 查明文件是否仍被代码、主页、其他文档或任务入口引用，读取全部独特规则。
2. 逐条归入唯一归属文档；冲突先核对代码、现行裁决和任务授权，不能用“新文件”自动压过旧约束。
3. 更新入站链接。长期规则已全部吸收的交接或个人手册移入仓库外档案，记录原位置、来源提交、去向与文件摘要；不能把私人原文复制进公开归档目录。
4. 本次整理保留原始材料，不物理删除。日后若删除需有明确授权，且先确认没有独特规则和有效引用。构建缓存不会因文档清理一并删除。
5. 旧路径只有仍有外部使用者时保留短迁移指针；它不再承载规则，不要求读者全文阅读旧档案。

## 提交前门禁

运行 pnpm docs:check（文档结构与公开边界检查）及 git diff --check（差异空白检查）；修改维护工具时再运行 pnpm test:maintenance（维护工具测试）。检查暂存列表及内容，确认没有私人路径、服务器地址、凭据、环境文件、原始会话和本地工具缓存。

检查器同时查看已跟踪文件和未忽略的新文件，但不会读取被忽略的私人资料。它拒绝常见秘密形态和私人文件名，并检查维护文档里的个人目录；它不是通用秘密检测服务，不能因此省略人工核对。发现已发布的真实秘密时停止继续传播并报告，不能以删除当前文件代替轮换或授权的历史处理。
