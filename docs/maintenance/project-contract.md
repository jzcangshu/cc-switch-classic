# 项目契约

修改产品代码前阅读；上游同步实现与审查都以本契约为经典版边界。

## 产品与数据

- CC Switch Classic（经典版配置切换器）采用官方第四版内核，保留第三版 v3.20.4（视觉参照标签）的操作与外观。后端、协议、数据迁移、业务逻辑默认跟进上游；不能为复古界面删掉有效能力。
- 产品名称、反馈入口、下载和自动更新使用本项目身份。官方来源链接、许可证及历史发布说明可以保留上游署名；禁止的是把产品更新或支持入口误导到上游。
- 经典版版本与内核版本是两个独立维度；来源和修改清单见 [发布流程](release.md)，不得把读取应用内核版本的接口用于拼经典版发布链接。
- 语言仅保留 zh（简体中文）、zh-TW（繁体中文）、en（英文）、ja（日文）。旧的 tr（土耳其语）设置应回落英文，不恢复语言包、选项或类型分支。
- 不恢复赞助置顶预设、推广墙、推广追踪参数或相应排序字段；直营厂商的有效预设按产品用途保留。不用“仅保留登录类预设”的过滤方式裁剪其他应用配置；不要把某次扫描的供应商数量写成永久规则。
- 官方认证、第三方密钥、代理路由、原生配置和用户数据必须区分归属；切换模式不得覆盖不属于该模式的凭据或会话。

## 三条适配判断

仅当三项都满足时恢复第三版形态：

1. 成本为易改或中等；第三版无对应物时只裁剪纯界面附加物，带数据、带功能的新增保留。
2. 不引入大量逻辑重构、错误事实或严重体验退化，包括遮挡、溢出、触屏不可用和丢失防误操作保护。
3. 改动针对旧用户明显陌生的外观或入口；纯行为优化、默认值优化和信息增加默认保留上游。额度默认显示“已用”是已有明确例外，相关设置仍保留。

发生结构性冲突时保留新能力并记录原因，不自行发明“复古”布局。文案先还原为实际显示文字，再对照第三版；事实准确性优先于旧文字。

## 已确立的边界与反例

- 功能入口优先恢复为已有形态。例如供应商搜索使用浮动面板，不能直接删掉搜索。
- 保留未保存离开确认、删除确认与撤销、禁用原因、搜索时限制收起、直连格式警告及目录草稿保护。
- 保留“查看模式”和“实际生效模式”的区别、会话结构化时间线、技能批量操作折叠区；这些不是可以随皮肤一起替换的视觉细节。
- 提示词内页头、原生键名驱动的协议编辑抽屉、会话阅读器结构可继续采用上游模型，不以形似第三版为由破坏功能。
- 页面级小节结构恢复时，同时恢复该结构的常驻说明；不要单独大范围反向恢复字段小字。
- 保留滚动条可见、自绘输入、浮层动画、主题切换、中文字体栈、键盘焦点等底层可用性修复。
- 常用操作采用常驻按钮；卡片悬停操作在触屏、窄屏可直接访问。菜单继续承载上游新增的次要功能。
- 用量页保留玻璃汇总卡、独立筛选与趋势图指标切换，保留上游新增的成功率和币种换算。用量显示及列选择留在设置中；不恢复上游整套用量抽屉和级联筛选。
- 应用管理保留卡片网格，吸收已安装分组和拖动能力，并内嵌关于页。账号行不改回只靠省略号菜单操作；预设默认折叠，自定义配置入口常驻。
- 不带回上游专用的赞助、所有者或自动发布配置。本项目自行维护公开助手入口和持续集成；旧规则中“不上传任何助手文件”已由 [文档分层决策](../decisions/implemented/process/2026-11-04-maintenance-docs.md) 取代。

## 每次内核同步都要检查的界面区域

逐行在审查记录填写通过、缺陷或不适用及理由；只有截图不能证明行为，只有测试不能证明视觉。

| 区域       | 必须保留的形态与行为                                                                                                       |
| ---------- | -------------------------------------------------------------------------------------------------------------------------- |
| 窗口与页头 | Windows（微软桌面系统）原生标题栏；跨平台拖动和缩放；移除旧模式徽章堆叠；品牌指向本项目；独立用量与更新入口                |
| 供应商     | 橙色圆形添加按钮、蓝色加入按钮、主色禁用的使用中状态；搜索浮动面板；默认操作直显；移除官方徽章、整卡变淡及旧队列上下移按钮 |
| 卡片与额度 | 操作组悬停、触屏和窄屏可达；额度默认已用；失败胶囊保留错误详情；长地址、套餐后缀和图标不重叠                               |
| 认证中心   | 标题、简介与组名副标题一致；重新登录、使用账号、删除入口可达；账号组与额度列在临界宽度不溢出                               |
| 路由与扩展 | 路由手风琴；MCP（模型上下文协议）按钮和自定义胶囊；技能搜索及数量栏；Pi（编程工具）模板编辑删除直显                        |
| 设置       | 蓝底白字胶囊页签；配置目录紧凑单列；通用页小节及内联说明；数据来源三卡、模型元数据整卡                                     |
| 关于与应用 | 第三版关于页版式，同时保留近期更新、便携提示和内嵌应用管理；应用网格与环境徽章                                             |
| 会话与用量 | 恢复命令预览条、常驻删除及结构化阅读；玻璃汇总卡、有效高度的趋势图和准确的数据                                             |
| 公共组件   | 二级页完整标题；对话框暗化毛玻璃遮罩、浅色标题与底部条带；主题、焦点、滚动和长文本正常                                     |

视觉依据来自对应标签的源码与实际渲染，不把某次截图的像素宽度、测试数量或内核版本当成永久契约。
