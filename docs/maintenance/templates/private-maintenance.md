# 私人维护说明模板

本模板可以公开。填写真实值之前，复制到仓库外受访问权限保护的私人目录；禁止把填写后的副本提交到任何公开分支。不要在本文填密码、令牌或密钥正文。

## 与公开流程的关系

从项目的统一入口按阶段读取规范。本文件只解释本人环境如何执行，不覆盖产品契约。其他贡献者不需要它。

## 本地执行信息

- 本人开发目录与工作区用途：待填写。
- 实际远端映射和允许推送的仓库：待填写。
- 工具链、磁盘空间、构建输出位置及资源限制：待填写。
- 网络代理与服务端连接方式：待填写；凭据通过密码管理器或环境变量取得。
- 测试隔离目录、端口与启动中的桌面应用：待填写。
- 截图、调试和私人辅助脚本位置：待填写。

## 发布与恢复

- 签名材料的安全存放位置及注入方式：待填写，不复制正文。
- 发布平台授权身份及恢复渠道：待填写。
- 私人服务器备份、恢复与权限检查：待填写。
- 档案目录、原材料清单和保留期限：待填写。

## 瞬时状态

记录核实日期、分支和完整提交编号；明确已发布、已推送、已完成但未合并、尚待验证的区别。切换任务时重新核对，不能把状态变成长久规则。
