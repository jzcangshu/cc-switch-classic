# 应用内更新摘要

本目录的产品摘要使用经典版版本号，构建时由 src/lib/whatsNew.ts（摘要读取模块）载入。写作前按 [发布流程](../../docs/maintenance/release.md) 核对版本，不能用内核版本号替代。

## 文件与格式

每个经典版版本对应一个同名的 JSON（结构化数据）文件；version（版本字段）与文件名一致，items（条目列表）每项包含 type（类型）及 zh（简体中文）、zh-TW（繁体中文）、en（英文）、ja（日文）四个翻译。

- 类型为 new（新增）、fix（修复）、improve（改进）。
- 每版最多四条，每条一句话：简繁中文各不超过四十字，日文不超过五十字，英文不超过一百字符。
- 写实际已集成、用户可感知的变化，不把未合入的官方内核变化算作产品能力。
- 空条目列表表示本版不弹摘要，适用于只有构建或自动检查变化的版本；发版检查仍要求对应文件存在。

规则由 tests/config/whatsNewEntries.test.ts（摘要守卫测试）验证。新增或调整规则时同时核对读取模块、弹窗、测试和发布工作流。

## 链接与发布时机

本项目摘要详情链接到本项目的经典版发布标签，不能恢复上游官网日志地址。产品发布说明与历史内核说明要标明各自口径。

在打产品版本标签之前完成摘要、两处产品版本常量和主页版本信息；发布工作流检查相应摘要文件。历史内核摘要如仍由代码读取，保留其来源，不为目录整洁批量移除。
